# Design

## Goal

The goal of this exercise is to introduce conditionals in Bash scripts.

## Learning objectives

- Know that a zero exit status is "true" and a non-zero exit status is "false".
- Write an `if` command with `then` and `else` branches.
- Write an `if` command with `elif` branches.
- Use `[[ ... ]]` to compare strings for equality with `==`.
- Combine two comparisons within `[[ ... ]]` with `||`.
- Compare strings in dictionary order with `<` within `[[ ... ]]`.
- Compare integers with `-lt` and `-gt`.

## Out of scope

- The `case` command.
- Using `&&` and `||` between commands as a replacement for `if`.
- The differences between `[`, `test` and `[[` in depth.
- Arithmetic expansion and the `(( ... ))` command.

## Concepts

The Concepts this exercise unlocks are:

- `conditionals`

## Prerequisites

- `quoting`
